# Translator Chat Bot

Discord에서 한국어와 일본어 간의 실시간 번역을 지원하는 번역 봇 프로젝트입니다.

## 프로젝트 목표

* Discord Bot 기반 실시간 번역 서비스
* 한국어 ↔ 일본어 자동 번역
* 번역 결과 자동 출력
* 번역 이력 저장

## 기술 스택

### Backend

* Java 21
* Spring Boot
* JDA

### Database

* MySQL
